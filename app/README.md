# Flutter App

請從 repository 根目錄 [README](../README.md) 與 [開發文件](../docs/development-environment.md) 開始。

- `lib/app/`：應用程式組裝、theme、locale。
- `lib/features/home/`：啟動 Use Case、Repository、ViewModel、View。
- `lib/core/database/`：平台儲存 Service、versioned migration。
- `test/`：unit、widget、SQLite migration 測試。
- `integration_test/`：原生平台儲存開啟／重開與 Shell smoke test。
- `tool/check_sdk.dart`：精確 SDK 版本檢查。

目前只提供空資料 Shell；教材與學習流程於 Phase 1 實作。
